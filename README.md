# Biblioteca Escolar — EB D. Fernando II

Aplicações da equipa da Biblioteca Escolar (Agrupamento de Escolas Monte da Lua).

- `index.html` — página de entrada com dois botões: **Balcão** e **Estatísticas**.
- `codigo/` — cópia de segurança do código do Google Apps Script:
  - `Code.gs` — servidor (lê e grava na folha de cálculo da biblioteca)
  - `Balcao.html` — app da equipa: Requisições, Atividade, Espaço, Em atraso
  - `Index.html` — painel de estatísticas

O código em `codigo/` só funciona dentro do Google Apps Script (conta bibdf@essmaria.net).
Não abre sozinho no GitHub: serve de cópia de segurança. Para repor, colar cada ficheiro
no projeto Apps Script com o mesmo nome e fazer Implementar → Gerir implementações → Versão nova.
